# Cam2app — عين المنزل

كاميرا مراقبة ذكية تشتغل من المتصفح بس — بدون تطبيق من المتجر، بدون سيرفر خاص بك.
تفتح الرابط على أي هاتف، يعطيها إذن الكاميرا، يربطها ببوت تيليجرام، وتصير
جاهزة ترسل تنبيه فوري (مع صورة) أول ما شخص يقرب من الكاميرا.

كل كشف الوجوه/الأجسام يصير **محلياً داخل المتصفح** (عبر face-api.js)،
وما في أي فيديو يترفع لأي سيرفر — الصورة الوحيدة اللي تطلع من الجهاز
هي صورة لحظة التنبيه نفسها، وتروح مباشرة من المتصفح إلى بوت تيليجرام
الخاص بك فقط.

## الرفع على GitHub

```bash
git init
git add .
git commit -m "Cam2app v1"
git branch -M main
git remote add origin https://github.com/USERNAME/cam2app.git
git push -u origin main
```

## النشر على Vercel (دقيقتين)

1. روح [vercel.com](https://vercel.com) وسجل دخول بحساب GitHub
2. **Add New → Project** واختر الريبو `cam2app`
3. Framework Preset خليه **Other** (الموقع ثابت، ما يحتاج build)
4. اضغط **Deploy**

بعد ما يخلص، يعطيك رابط زي `cam2app.vercel.app` — هذا الرابط هو
التطبيق، وأي تحديث تسويه وتعمله `git push` ينشر تلقائياً.

## كيف يفتحه أي شخص على هاتفه

ترسل له رابط Vercel بس. أول ما يفتحه:
1. يمشي على ويزرد إعداد من ٣ خطوات (إذن الكاميرا → بوت تيليجرام → تم)
2. بعدها يقدر يضيفه لشاشته الرئيسية (**Add to Home Screen** من قائمة
   المتصفح) ويفتح بعدها زي أي تطبيق عادي، بأيقونته الخاصة

كل مستخدم يربط بوت تيليجرام خاص فيه (التعليمات داخل التطبيق)، فكل
واحد يستقبل تنبيهاته هو بس.

## تخصيص سريع

| تبي تغيّر | وين |
|---|---|
| الألوان / الثيم | `style.css` (متغيرات `:root` في الأعلى) |
| نص التنبيه | دالة `fireAlert()` في `app.js` |
| حساسية الاقتراب الافتراضية | `renderWizard`/`sensitivity` في `app.js` |
| مدة الكولداون بين التنبيهات | `20000` (بالميلي ثانية) داخل `checkProximity()` |
| الأيقونة | ملفات PNG داخل `icons/` |

## ملاحظات تقنية

- الكاميرا تحتاج **HTTPS** عشان تشتغل من المتصفح — Vercel يعطيك
  هذا تلقائياً، فما تحتاج تسوي شي إضافي.
- نموذج الكشف (face-api.js) يتحمّل من CDN أول مرة تفتح فيها
  الصفحة، وبعدها الـ Service Worker يخزّن ملفات التطبيق نفسها
  للعمل بدون نت لاحقاً (ماعدا الكشف والتنبيهات، تلزمها شبكة).
- لو حبيت لاحقاً تحوّله Self-Hosted على جهازك (زي ما تخطط)، نفس
  الملفات تشتغل من أي سيرفر ستاتيك (nginx، Caddy..) بدون تعديل —
  بس خلي عندك شهادة HTTPS حتى محلياً عشان الكاميرا تسمح.
